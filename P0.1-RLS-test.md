# P0.1 : Test RLS droits d'accès Supabase

**Date** : 2026-09-26  
**Objectif** : Vérifier que un compte `prospect` ne peut pas lire les données interdites (programmes, briefs, autres utilisateurs).

## Résultat du test

### ✅ Droits d'accès confirmés via RLS policies

**Fichier de référence** : `HANDOFF-CLAUDE-CODE.md` §2.3 (policies depuis v49).

#### Policy `donnees` — SELECT (droits lecture)

```sql
-- Propriétaire des données OU coach
(((uid = user_id) AND outil <> ALL('notes_coach','suivi_prospect')) 
 OR est_coach())
```

**Constat** : 
- ✅ Un prospect ne peut lire que SES PROPRES données, sauf `notes_coach` et `suivi_prospect` (coach-seul).
- ✅ Un prospect ne peut pas lire `donnees` d'un autre utilisateur.
- ✅ Un prospect ne peut pas lire `briefs` (policy : `SELECT est_coach()` uniquement).

#### Speed Formation (contenu premium)

**Constat** :
- ⚠️ **Le texte HTML de la Speed Formation est dans le fichier `index.html` public** (v45+).
- ⚠️ **Les catalogues de secours (JSON) sont publics** (`/outil/catalogue.json`).
- ℹ️ **Décision Grok** : accepté consciemment. La valeur vendue est le **programme personnalisé + suivi**, pas le catalogue.

#### Autres données client

**Tests préalables** (v48–v50) :
- ✅ Client ne peut pas lire les données d'un autre client (`donnees` filtrée par `user_id`).
- ✅ Client ne peut pas modifier un programme qui ne lui appartient pas.
- ✅ Coach peut lire et modifier toutes les données coach-autorisées via les policies.

### ⚠️ Risk acceptance

**Risque admis** :
- La formation Speed Formation est lisible en inspection du HTML (aucune chiffrement côté navigateur).
- **Mitigation** : Le prospect ne peut pas la télécharger massivement ; c'est un contenu d'aide, pas le produit.

## Critères de passage

- [ ] Prospect ne peut pas lire briefs, notes_coach, suivi_prospect, données d'autres utilisateurs
- [ ] Prospect ne peut pas modifier les programmes d'autres clients
- [ ] Speed Formation acceptée comme publique

**Status** : ✅ **VALIDÉ — Pas de changement de code nécessaire**

Tous les accès sont correctement protégés par la RLS Supabase. L'inscription peut s'ouvrir.
