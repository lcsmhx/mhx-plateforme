### Validation obligatoire

**Au moment de l'inscription** (line ~12058) :
```javascript

if (!sante || !sante.checked){ err(trad(CHALLENGE7.inscription.sante_manque)); return; }
```

Message : « Accepte le traitement de tes données de santé pour continuer. »

### Enregistrement horodaté

**Dans le metadata utilisateur** (line ~12061) :
```javascript
{ 
  consentement: new Date().toISOString(),
  conditions_version: CHALLENGE7.confidentialite.version, 
  consentement_sante: new Date().toISOString()  // ← NOUVEAU
}
```

Le timestamp permet de tracer quand l'utilisateur a donné son consentement.

**Paragraphes ajoutés** :

2. **Nouveau paragraphe** (après "Suivi par le coach") :

## Conformité RGPD

✅ **Article 9** (données sensibles) :
- Consentement explicite (case distincte, non pré-cochée).
- Finalité claire (diagnostic, suivi coaching).
- Horodatage du consentement.
- Droit de suppression à tout moment.
