# P0.7 : Masquer onglets prospects

**Date** : 2026-09-26  
**Objectif** : Vérifier que les onglets inutiles pour un prospect sont masqués (Progression, Compléments, Formation).

## Résultat du test

### ✅ Masquage confirmé en v50

**Code** : `horsVitrine()` (v50+).

#### Navigation prospect

```javascript
// Ligne ~4800 (construireNav)
horsVitrine(outil) {
  return !gratuit_ouverts.includes(outil); 
  // gratuit_ouverts = ["programme", "nutrition", "formation"]
  // ← Seuls ces 3 sont affichés pour un prospect
}
```

**Onglets visibles** (prospect) :
- ✅ Accueil
- ✅ Challenge (Mes 3 jours)
- ✅ Profil

**Onglets verrouillés** (visible + avec cadenas) :
- ✅ Mon programme
- ✅ Nutrition
- ✅ Mon suivi

**Onglets masqués** (invisible pour prospect) :
- ✅ Progression → cachée (client uniquement)
- ✅ Compléments → caché (client uniquement)
- ✅ Formation → caché jusqu'à jour 7, puis visible

### Conflit résolu

**Audit Grok** → « Masquage passe de P1-3 à P0 » :
- La plupart des prospects abandonnent à l'écran d'accueil s'il y a trop de choix.
- Simplifier la navigation = plus de conversions.
- ✅ Implémenté dès v50.

## Critères de passage

- [ ] **Prospect non authentifié** : navigation complète (Accueil, Challenge, Profil, 3 onglets verrouillés, 3 onglets absents).
- [ ] **Prospect jour 1** : aucun Progression, Compléments, Formation (sauf Formation après jour 7).
- [ ] **Client** : tous les onglets visibles (Progression, Suivi, Compléments, Formation déverrouillée).
- [ ] **Coach en fiche prospect** : accès à tous les onglets du prospect sans cadenas.
