# P0.4 : Doublons email (message clair)

**Date** : 2026-09-26  
**Objectif** : Détecter quand un email est déjà utilisé et afficher un message clair.

## Décision prise

**Confirmation d'email** : Désactivée pour 30 jours (du 26/09 au 26/10/2026).

**Raison** (audit Grok, angle mort 3) :
- Avec confirmation activée, Supabase répond « succès » même si l'email existe déjà (sans erreur).
- Le message « Un compte avec cet email existe déjà » du code ne s'affichera jamais.
- Le prospect attend un email de confirmation qui ne vient pas.

## Configuration Supabase

**À faire par Lucas** (hors app) :
- Supabase Console → Project Settings → Auth → Email Settings.
- **Uncheck** : « Confirm email ».
- Save.

**Résultat** :
- Les comptes sont créés immédiatement, connectés sans vérifier l'email.
- Si email doublon : Supabase renvoie `identity_already_exists` ou `user_already_exists` → message affiché.

## Code existant

Le message existe déjà en v50 (ligne ~800) :

```javascript
if (msg.includes("already_exists") || msg.includes("User already exists")) {
  return "Un compte avec cet email existe déjà : connecte-toi avec ton mot de passe " +
         "ou utilise « Mot de passe oublié ? »";
}
```

**Constat** : ✅ Le message s'affichera correctement quand la confirmation sera désactivée.
